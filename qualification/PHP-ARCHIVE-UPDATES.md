# Retired PHP archive mirror

Durable Workflow retired its PHP archive mirror. Do not recreate the repository
or create a replacement mirror. Current CI uses the repository's reviewed PHP
container or the approved hosted PHP setup with fixed APT and live Composer
trust verification.

The pinned action, qualification fixtures and frozen policy data preserve
evidence about earlier runs. They are historical and should not be used to set
up new jobs or update active PHP pins.
