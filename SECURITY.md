# Security policy

## Security maintainer

Richard McDaniel (@rmcdaniel) is the sole maintainer and security maintainer of Durable Workflow.

His security responsibilities include reviewing vulnerability reports, assessing security issues, developing and reviewing fixes, adding security regression tests, and coordinating security updates and disclosures.

These responsibilities cover the Durable Workflow repositories he maintains, including the core workflow runtime, orchestration server, Waterline, PHP/Python/Rust SDKs, and command-line tooling.
